# Spendly

A personal finance / expense tracker. Start with
[`docs/project_overview.md`](docs/project_overview.md) for the product pitch,
[`docs/progress.md`](docs/progress.md) for what's built so far, and
[`docs/project_flow.md`](docs/project_flow.md) for the full tech stack,
architecture, and phased roadmap. [`docs/PRODUCT_PLAN.md`](docs/PRODUCT_PLAN.md)
has the condensed original plan.

- `frontend/` — the app (React + TypeScript + Vite + Tailwind), runnable today
- `backend/` — folder scaffold only, no logic yet (planned: Django + DRF)
- `database/` — folder scaffold only, no schema yet (planned: PostgreSQL)

## Running the frontend

```
cd frontend
npm install
npm run dev
```
